01

选好模型和分组

先在模型广场确认支持的模型、分组、倍率和价格。同一个模型在不同分组可能有不同计费，创建密钥时选择你要使用的那一组。

确认额度再调用
按量分组使用账户余额，订阅分组需要对应的有效订阅。可在「充值/订阅」购买，在「我的订阅」查看额度和有效期。订阅分组的可选范围以账号当前权限为准。
打开模型广场 ↗充值或订阅 ↗我的订阅 ↗
02

创建 API 密钥

登录后进入「API 密钥」，点击右上角「创建密钥」。一把密钥绑定一个分组，客户端通过这把密钥使用该分组支持的模型。

  1. 填写一个易认的名称例如我的 Codex 或工作电脑，方便以后区分。
  2. 选择厂商GPT 选 OpenAI，Claude 选 Anthropic；DeepSeek 等在国产模型中。
  3. 选择对应分组后创建核对分组和倍率。额度限制、有效期等按需设置。
前往 API 密钥 ↗

安装 CC Switch

CC Switch 简称 CCS，用来导入和切换连接配置。首次使用先安装桌面版，已经安装可直接继续下一步。

从官方获取安装包

选择与你的系统和芯片匹配的版本

官方 Releases ↗官方网站 ↗
安装后打开一次 CC Switch。网页通过 ccswitch:// 唤起本机应用，浏览器询问时允许打开。若没有反应，见下方导入问题。
03

把密钥导入 CCS

回到「API 密钥」，找到刚创建的密钥，点击这一行操作栏里的「导入到 CCS」，在 CC Switch 中确认导入并启用配置。

OpenAI 分组 → CodexAnthropic 分组 → ClaudeGemini 分组 → Gemini

导入目标会按分组平台识别；Antigravity 分组会先让你选择 Claude 或 Gemini。其他客户端可点击同一行「使用密钥」，按页面提供的配置接入。

导入后记得启用
在 CC Switch 里确认当前客户端选中了刚导入的配置。不要分享密钥或包含密钥的导入链接。
04

发起第一次调用

重新打开你使用的客户端切换配置后重启 Codex 或 Claude Code，让它读取新配置。CCS 已支持的会话兼容处理按客户端提示操作即可。
先发送一条简短请求使用当前分组支持的模型。收到回复后，到「使用记录」核对模型、分组和费用。
使用记录 ↗查请求和费用渠道状态 ↗确认服务可用情况我的订阅 ↗看额度和有效期

卡在哪一步

先看错误信息，再检查密钥、分组、额度和客户端配置。

点击导入到 CCS 没有反应

先确认已安装并打开过 CC Switch，再允许浏览器打开外部应用。仍无反应时重新安装官方桌面版，让系统注册 ccswitch:// 协议，再重试导入。

创建密钥时找不到想用的分组

先核对所选厂商。订阅分组还需要对应的有效订阅；购买后可刷新「API 密钥」页面。仍不可选时联系支持，提供分组名称即可。

已经导入 但客户端仍在使用旧配置

在 CCS 中切到正确的客户端，启用刚导入的配置，再完全退出并重新打开该客户端。还不生效时，检查客户端是否另有配置覆盖了当前连接。

401 认证失败

确认使用的是本站生成且处于启用状态的 API 密钥。手动配置时检查复制是否完整、API 地址是否填错；密钥失效后重新创建并导入。

403 无权限或额度不可用

按返回信息检查密钥绑定的分组、账户余额、对应订阅与额度限制。订阅有额度不代表所有分组都能使用；同时确认请求的模型属于该分组。

429 请求过多

降低同时运行的任务数量，稍后重试。检查密钥的速率限制，以及账号或分组的并发限制。若只有某个模型持续出现问题，再查看「渠道状态」。

模型不可用或请求失败

到「模型广场」核对模型名称和所属分组，避免把另一个分组的模型直接填入。短时服务异常可查看「渠道状态」；持续失败时保留报错和时间联系支持。

还没接通

发送客户端名称、分组名称、报错截图和发生时间
