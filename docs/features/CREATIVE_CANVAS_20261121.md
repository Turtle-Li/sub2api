# 创作画布：让一张图长出几个镜头

**阶段：接入提案与离线交互样机，不是已接入的业务路由。** 建议在「生图工作台」「视频工作台」旁增加独立的「创作画布」。只做一次生成时仍用原工作台；需要铺开素材、比较镜头、回看创作关系时再进画布。不要把画廊改成画布，也不要求生图详情重构配合上线。

## 第一条值得打通的路径

用户将自己画廊里的一张图加入画布。选中图片，点「建视频草稿」，保留原图并画一条指向新草稿的线；重复此动作，可以一边试推镜头、一边试固定机位。两条线说明来源，不代表执行顺序。点草稿进入**现有视频工作台**，在那儿确认模型、素材、报价并手动生成。成功后，用同一个工作台任务号将成片挂回对应分支。先打开了画布也可以从文字构思开始，再去生图工作台；第一版优先完成图→视频，不把节点做成另一套参数表单。

## 数据、权限、费用

- 画布持久化 `id / revision / title`、世界坐标与视口、节点/边、用户主动保存的便签或草稿，以及受限作品引用。边只表达「基于这个输入」，不能触发工作流。服务端从登录态确定所有者，按本人画布授权；不信任客户端传来的用户、分组、Key 槽或任意 URL。每次取素材重新检查原权限、归属和时效。旧 Key 作品必须保持其原授权，不替换成当前 Key。
- 只存内部标识：视频工作台任务 ID；图片使用服务器校验过的任务、条目和序号及原路由绑定。不存上游 URL、签名 URL、Key 值、媒体 Blob/Base64 或播放器地址。原图短期传递只在当前用户的标签页有效，不能当作跨刷新缓存。失效素材保留位置并提示「素材已失效，可重新选择」，不后台重生、不自动用缩略图顶替。
- 打开、挪动、连线、恢复、创建草稿和返回不触发生成、扣费或上游轮询。画布保存只写本人的布局和草稿。花钱的动作始终留在既有工作台，沿用服务端目录/报价/钱包、`request_id` 和原回执；双击、刷新、回退、断网均不得重发。作品节点有真实封面才显示封面，有文件时长才显示时长。删除节点只解除引用，不删除原作品或取消其任务。
- 服务端限制画布/节点数量、文字长度、可接受类型与坐标；拒绝跨画布引用、无端点/重复边、衍生自环和循环。使用修订号做乐观并发；两个标签页冲突提示恢复，不用「最后一次写入」覆盖他人的新草稿。首版不含多人协作、分享链接、自动跑全图、任意脚本或第三方模板市场。

## 落地顺序与验收门槛

1. **确认交互**（本轮）：离线样片、移动节点/视口、保存原图并建多个视频分支。此步骤不保存到用户账号，也不模拟成功订单。
2. **只读素材板**：实现受控入口和本人画布存取；先允许「加入已有作品」。验收跨用户不可读、素材过期可见占位，缩放/拖动/刷新不读取完整视频或产生生成请求，坐标含 0 可恢复。
3. **草稿往返**：图→视频优先；随后补文字→生图。手动进入现有创作栏，快照报价已过期时重新确认。请求号与节点绑定在刷新/断线后仍可找回同一结果；旧源图和其它分支保留。验证无个人 Key、按渠道分组扣款、未确认零请求，流水有且仅有一笔。联调只用本地模拟；需要渠道烟测时仅按授权使用 Muse，**不请求 H3**。
4. **灰度前**：桌面与手机真实浏览器测触控、键盘、全览和较多节点时的预览开销；通过隐私/归属与幂等门禁再开开关。回退关闭画布入口，原工作台、钱包、已保存作品与任务不变。

## 已验证的离线样机

Gemini 4 通过 Antigravity CLI 设计并实现。桌面 1440×900 和手机 390×844 真浏览器均验证：拖原图连线跟随、空白平移、滚轮或双指缩放、全览、从同一原图再建一条草稿且原图不动，三条分支可比；编辑运镜后交接预览保留原文，不跳转、不发生成。初版有分支互相遮挡、手机首次进入时卡片太小、文字 `<wide>` 不按原样显示的问题。对照实际画面修订后重新验证：默认和新增草稿节点不重叠，手机默认聚焦原图且可回全览，文字按字面显示。仅有本地 HTML 和三张 JPEG 请求，没有业务接口或外部请求。

本机完整样机在项目根 `.omo/evidence/video-media-duration-canvas/board-demo/index.html`，用浏览器打开时保留旁边的 `media/` 目录。相邻的 `board-final/` 有两端实屏和操作结果，`acceptance.json` 同时记录时长变更的独立验收。本轮没有建设画布数据库、授权解析、正式路由或生成回挂；样机内容刷新即还原。
