## DeepSeek 文案

原生交付模板和共用指南删除指定句子。对已有原生 DeepSeek 订单，读取交付结果
和发送尚未发出的邮件时，仅过滤这条精确旧行（含旧空格写法），展示和完整复制
均不再包含它。不重新加密或改写已保存的交付；人工/HTTP 服务原文不套此过滤。

到期时间文本统一为 `到期时间：YYYY-MM-DD HH:mm:ss（北京时间 UTC+8）`，使用
明确的 Asia/Shanghai UTC+8 展示。已有原生内容中的精确 `到期时间：...（UTC）`
行在读取/邮件呈现时换算；重复呈现不再次加8小时，无法解析的原文保留。
实际到期 Unix 时间仍是原始 paid_at 加所购时长，不延长或缩短授权，也不依赖
浏览器/应用主机本地时区。增加跨北京时间日期边界、新交付与旧呈现回归用例。
