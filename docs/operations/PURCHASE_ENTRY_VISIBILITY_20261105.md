# 商城与充值/订阅入口显示开关

用户于 2026-11-05 明确简化需求：只控制显示/隐藏，不做用户名单或新增购买权限限制。

设置位置：**系统设置 → 功能开关 → 购买入口**。两个开关分别为“显示商城入口”和“显示充值/订阅入口”，通过页面原有保存按钮保存。

- 商城使用 `shop_entry_enabled`，控制用户侧边栏及订单页“前往商城”。未配置时默认显示。
- 充值/订阅复用 `payment_entry_enabled`，从支付设置移动到功能开关，原有配置值不变，继续控制原有购买导航和充值/续费入口。
- 只影响入口显示，直接链接、订单、支付恢复、交付、使用指南和已有订阅权益不新增限制。支付总开关和现有商品受众规则保持原样。
- 两个设置均沿用支付配置的可选字段更新机制，省略时保留原值；公共设置 API 和 HTML 注入同时投影，避免刷新时入口闪现。

本次不修改线上商品、价格或开关值。回退可还原代码；新键不影响旧版本，原充值入口设置不迁移。
