## Rollback fence

Use only the current AWS canonical blue-green receiver/helper and a verified
image. Preserve paid-reserve tags, usage/financial history, model mappings,
group allowlists and explicit flat-price configuration. Do not restore an old
full database, operate retired hosts, or bypass the fixed-egress retirement
fences. An old binary predating reserve isolation is not a safe rollback.
