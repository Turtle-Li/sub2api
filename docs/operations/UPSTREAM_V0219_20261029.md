## Merge contracts and intentional differences

Twenty-one files required conflict resolution. The source and tests at the
fixed upstream revision were compared with the fork before combining them.

- `backend/internal/repository/account_repo.go` and
  `custom_admin_key_scope.go`: use the upstream transaction scoping and scoped
  group writes together with local fixed-egress parent/shadow locks, atomic
  deletion, managed paid-reserve fields and scheduler retirement fences.
  Reuse `loadAccountGroupIDsWithClient` and deleted-account retirement rather
  than introducing the upstream's weaker cache deletion helper.
- `account_repo_grok_models.go` / `account_repo_grok_models_integration_test.go`:
  catalog CAS preserves unrelated fields and rejects stale snapshots. Both a
  context transaction and an injected transaction defer cache publication.
  The upstream integration test expected publication from an uncommitted
  injected transaction; the fork intentionally requires no publication.
  Upstream `account_repo_grok_models_test.go` separately covers publication
  outside a transaction. Protected/deleted retirement remains authoritative.
- `api_key_auth_cache_impl.go`: bump the snapshot layout to 26. Both branches
  called different layouts 25. Preserve local model allowlists, fast routing
  and model manifests while adding `image_count_billing`; old entries miss.
- `openai_images.go`, `openai_images_responses.go`,
  `openai_gateway_service.go`, `openai_gateway_usage.go`: mark all dedicated
  image transports with `ImageEndpoint`, preserving exact-N delivery, shortfall
  filling, overdelivery discard, partial-output failover protection, separate
  billable usage, requested-tier pricing and private upscale integration.
  The fork does not replace its delivered-image cap with uncapped upstream
  counts or synthesize a billable image when no image was delivered.
- `admin_group.go`: preserve local OpenAI batch support while adding the
  upstream opt-in OpenAI/Composite image-count billing setting.
- `billing_service.go` and tests: adopt permanent DeepSeek Pro prices and
  Terra support while retaining authored group/channel pricing priority,
  local Luna prices, hidden multipliers and internal-credit numeric rules.
- `setting_repo.go`, `setting_service.go`, `wire.go`: retain unified-payment
  CAS/idempotency commits and paid-fallback services alongside scoped keys.
  Unknown local routes remain denied to scoped keys by the upstream explicit
  method/path permission catalog.
- `backend/ent` and `backend/cmd/server/wire_gen.go`: regenerate from the merged
  schema and providers. Git's positional Ent merge otherwise initializes a
  float default from a bool field and panics at startup; the regenerated sort
  index and field offsets must ship together.
- Go dependencies adopt upstream crypto/net/sync/term/sys/text security updates
  while retaining the fork's newer `golang.org/x/image v0.45.0` and Go 1.27.3.
  Release workflows remain manual and AWS-only.
- The account editor retains local Cline/ModelTrace fields and adds upstream
  Grok diagnostics using the existing UI. Cline managed pin keys remain in
  ordinary-edit deletion and preservation lists.
