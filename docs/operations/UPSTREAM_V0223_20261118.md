## Merge contracts

- Adopt GPT-6.2 Sol/Astra metadata, plan-based Ultra Fast availability, and
  request-time promotional pricing. A channel can override the Ultra Fast
  multiplier independently from Fast and Flex. Unset overrides retain model
  defaults. Deployment does not edit account plans, group rules, or prices.
- Read and write the new multiplier alongside the fork's authored currency,
  time bands, and reasoning multipliers. Preserve the existing wallet
  settlement and provider-cost basis.
- Carry Anthropic 5-minute and 1-hour cache writes through gateway usage and
  billing while keeping the distinct OpenAI 30-minute and 12-hour buckets.
  Keep actual upstream consumption separate from customer-billable image
  usage after internal compensation. Account quota fallback still uses the
  fork's reference cost basis.
- Use the upstream one-switch budget for an idle OpenAI stream before model
  output. Retain partial-output handling and the fork's account admission and
  egress policy.

## Database and release

The only new migration is `252_channel_pricing_ultrafast_multiplier.sql`. It
adds a nullable numeric column and a positive-value check. The migration
runner keys on the full filename, so the already applied
`252_proxy_detected_timezone.sql` is unchanged. Existing cards keep their
currency and Fast multiplier. A prior binary can ignore the new column on
rollback; retain the migration and use the AWS blue-green rollback gates.

Release the exact fork `main` commit with the GitHub production workflow.
Keep the live ingress configuration and dispatch with `deploy_caddy=false`.
The standard receiver verifies the image, checks the candidate with Models
and Responses, switches the upstream and drains the former slot. See
[deployment instructions](../../deploy/README.md).
