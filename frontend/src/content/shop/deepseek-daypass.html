1. 领取 API Key

购买后可在「我的订单」查看 API Key 和套餐起止时间。续费沿用所选卡的 Key，客户端无需重新配置；另购会发放新 Key。

Key 是调用凭据，请妥善保存。不要公开分享或放进公开仓库。

2. 配置客户端

在支持 OpenAI 兼容接口的客户端中填写：

Base URL
https://ds.turtleligpt.com:24443/v1
API Key
订单交付的完整 Key，保留 sk- 前缀
模型 ID
deepseek-v4.1-flash 或 deepseek-v4-pro

客户端若会自动补上 /v1，请使用 https://ds.turtleligpt.com:24443，避免重复路径。请选择 Chat Completions 兼容模式。支持文本 Chat Completions、Completions 和 Messages 请求，以及流式输出；不含图片、音频或视频生成。

3. 并发与 IP 限制

并发数以当前生效的套餐档位为准，默认 2 并发。续购选了不同档位，会在新套餐生效时切换。

同一 Key 可同时使用一个公网 IPv4 和一个公网 IPv6，两者共享并发额度。更换同类出口 IP 前，请先停止调用 15 分钟。请勿转售或分发给多人共享。

收到并发限制时，等待已有请求结束再试。收到 IP 限制时，检查其他客户端、设备或代理是否仍在调用。

4. 有效期与售后

有效期按本单所选规格计算。未到期时续购，接在已有套餐之后；到期后续购，从新订单付款确认时起算。重复刷新或通知重试不会延长有效期。订单中的时间统一使用北京时间（UTC+8）。

有效期内不限 Token 总量，仍受并发、IP、上游可用性及上下文长度限制。没有生效的套餐时，Key 暂停调用，续购生效后可恢复使用。

如果付款后一直没有收到 Key，请刷新订单并联系客服，提供订单号。请勿向客服发送完整 Key。
